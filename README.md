# InkPDF (C++17 / Qt 6)

## ساخت روی ویندوز
1. نصب Qt 6 (فقط ماژول‌های Widgets و PDF)، Visual Studio 2022 و CMake
2. cmake -B build -S . -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2022_64"
3. cmake --build build --config Release
4. deploy.bat build\Release   (از Qt command prompt؛ فقط فایل‌های لازم کپی می‌شوند)

## کلیدها
P قلم | H هایلایت | L خط صاف | E پاک‌کن | T لیزر | M ماسک | C نوت | 1..6 رنگ | [ ] ضخامت
Ctrl+1..3 لایه فعال | Alt+1..3 نمایش/مخفی لایه | Alt+N نمایش نوت‌ها | F2 فهرست نکات
Ctrl+Z / Ctrl+Y واگرد/ازنو | Ctrl+چرخ ماوس زوم | N حالت شب | F11 حالت ارائه
Ctrl+S ذخیره | Ctrl+E خروجی PDF

## نوت
- با ابزار C روی صفحه بزنید: آیکون نوت ساخته می‌شود و کارت باز می‌شود
- روی کارت با قلم بنویسید؛ دکمه T متن تایپی، دکمه سنجاق برای ثابت ماندن، × برای بستن
- سربرگ را بکشید تا جابه‌جا شود؛ گوشه پایین را بکشید تا بزرگ/کوچک شود
- با یک ضربه سریع روی آیکون، کارت باز/بسته می‌شود
- نوشته‌ها کنار فایل (book.pdf.ink.json) ذخیره می‌شوند و فایل اصلی دست نمی‌خورد

## ساخت فایل نصبی (Setup.exe) به‌صورت خودکار
پروژه را در یک مخزن GitHub بگذارید، در تب Actions گزینه «Build installer» را Run کنید و بعد از چند دقیقه InkPDF-Setup.exe را از بخش Artifacts دانلود کنید.
