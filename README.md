# InkPDF (C++17 / Qt 6)

## ساخت فایل نصبی
پروژه را در GitHub بگذارید و از تب Actions گزینه «Build installer» را Run کنید؛ فایل InkPDF-Setup.exe در Artifacts است.
ساخت دستی: Qt 6 (Widgets + PDF) و Visual Studio 2022، سپس
  cmake -B build -S . -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2022_64"
  cmake --build build --config Release
  deploy.bat build\Release

## ابزارها و کلیدها
P قلم | H هایلایت متن (روی خود متن می‌نشیند؛ جایی که متن نیست مثل ماژیک آزاد می‌شود) | K ماژیک آزاد
اشکال: L خط، A پیکان، D پیکان دوطرفه، O بیضی/دایره، R مستطیل/مربع
E پاک‌کن | T لیزر (فقط هنگام لمس/کلیک) | M ماسک | C نوت
1..8 رنگ‌های سریع (راست‌کلیک روی هر رنگ یا دکمه پالت: تغییر رنگ)
[ ] ضخامت ابزار فعال | نوار «پایداری قلم»: ۰ = بدون صاف‌سازی، ۱۰ = بیشترین
Ctrl+1..3 لایه فعال | Alt+1..3 نمایش/مخفی لایه | Alt+N نمایش نوت‌ها | F2 فهرست نکات
F10 یا دکمه بالای صفحه: مخفی/نمایش دو ردیف نوار ابزار | F11 حالت ارائه
Ctrl+Z / Ctrl+Y واگرد/ازنو | Ctrl+چرخ ماوس زوم | N حالت شب | Ctrl+S ذخیره | Ctrl+E خروجی PDF

## نوت
با ابزار C روی صفحه بزنید؛ روی کارت با قلم بنویسید. دکمه‌های سربرگ: × بستن، سنجاق، T متن تایپی، پالت (رنگ و تم نوت).
نوشته‌ها کنار فایل (book.pdf.ink.json) ذخیره می‌شوند و فایل اصلی دست نمی‌خورد.
